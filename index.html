분야별 핵심 요약

논문 · 특허 성과 산출 개요

각 분야의 목표, 주요 KPI, 데이터 수집, 핵심 매칭 방식, 주요 이슈, 정확성 향상 방식을 정리한다.

논문

JCR 상위 10% 논문 성과

과기분야 사업 수행으로 산출된 JCR 피인용 상위 10% 학술지 게재 논문을 일관·재현 가능하게 자동 추출하여 경평 계량값을 산출한다.

주요 KPI
분야별 JCR 상위 10% 학술지 발표 논문 편수(지표는 ’21~’26 반영), 저자 매칭 기반 참여율·경평 산출값(주저자/공동저자 구분)
데이터 수집
  • 연계 DB: Web of Science(WoS) Open API
  • 수집 기간: 발행년도 2020~2026 (지표 ’21~’26 반영)
  • 검색 조건: Funding Agency = National Research Foundation of KOREA 또는 NRF of Korea
  • Document Types: Article, Review Article / Index: SCIE·A&HCI·SSCI
핵심 매칭 방식 — 저자명 매칭
과제번호 앵커링으로 후보군을 해당 과제 참여연구원(소규모)으로 한정한 뒤 판정
  • 방향1: 영문명 직접 매칭(대소문자·하이픈·공백·성명순서 무시)
  • 방향2: 국문명 로마자 변환 후 매칭
  • 방향3: 로마자 변환 규칙 다중화(성씨·이름형식·철자 변형 다발 생성)
  • 방향4: 이니셜 축약 대응(후보 내 유일 대응 시 확정)
  • 방향5: 퍼지 매칭으로 잔여 오차 흡수(편집거리·Jaro-Winkler)
주요 이슈
  • 검색 조건 표기 다양성으로 결과 상이
  • 다운로드 시점에 따라 동일 조건도 데이터가 달라지는 현상
  • 저자명 영한 변환 방식에 따라 참여율 산출 결과가 달라지는 구조적 한계
  • (자문) 과기분야 R&D 과제 시 SSCI 분야까지 JCR 리스트를 볼지 여부
정확성 향상 방식
정확히 매칭된 건만 우선 계산값 부여 후 개선 지속, 로마자 규칙 다중화·이니셜 대응으로 규칙 기반 매칭률 제고, AI(LLM)는 회색구간 재순위화 용도로만 제한적 활용
특허

지식재산권 국내외 등록건수

KIPRIS 등록특허에서 재단이 연구관리전문기관인 사사 특허를 자동 추출하고, 사사 내 전문기관 수로 기여율을 산출하며 국내·해외(삼극) 등록 여부까지 판정한다.

주요 KPI
지식재산권 국내외 등록 건수(’21~’26), 실적값 = 기여율 × 가중치
  • 가중치: KR=1, US·EP·JP=각 2, 삼극(3국 동시 등록)=10
  • 기여율 = 재단 과제(전문기관) 수 ÷ 해당 특허의 전체 지원기관 수(사사)
  • 삼극은 US·EP·JP ‘등록’ 동시 충족 시에만 인정
데이터 수집
  • 연계 DB: KIPRIS+ Open API
  • 국내: ’21~’26 등록일자 기준 전체 bulk 수집 → 서지상세에서 연구관리전문기관명(사사) 전량 파싱
  • 해외: 재단 특허의 패밀리 출원번호로 US·EP·JP 등록 여부 확인
  • 국내 모집단 소급 수집(해외등록 지연 감안)
핵심 매칭 방식 — 사사 판정 + 기관수 카운트
  • 재단 사사 판정: 연구관리전문기관명(rndSpecialInstituteName) 기준
  • 전문기관 수 카운트: 각 특허 사사표기를 파싱해 지원기관이 총 몇 개인지 산출 → 기여율 분모로 사용 (예: 전문기관 3개면 재단 기여율 1/3)
  • 제외사업 매칭: 엑셀(유형·사업명) 완전일치, 부분일치는 수기 검토(NTIS 과제 번호 매칭 등 활용)
  • 국내 출원번호 → 패밀리 → 삼극(US·EP·JP) 판정으로 개별 특허(행) 처리
주요 이슈
  • ‘연구관리전문기관명’ 검색 항목 미제공 → 사업명/과제명 동시 검색 한계
  • 사업명 입력 형태 다양성으로 정확 매칭 불가
  • 기존 크롤링 기반 파이썬 수작업 → 오류 시 데이터 누락 위험
  • (자문) 해외특허 서비스 활용신청, NTIS 연계 현황, 소급기간 확정
정확성 향상 방식
국내 모집단 소급기간 5년(1안)으로 확정(PCT·파리조약·국가별 심사적체 고려), 국가연구개발사업 미표기 건 수집 여부 검토, 사업명 vs NTIS 과제번호 방식 실익 비교 후 정책 결정

근본 문제의식

외부 DB의 검색 조건 다양성·다운로드 시점 편차, 담당자 수기 재검토 의존, 연구자의 자유로운 사사정보 입력(오기·누락)으로 인해 성과 산출의 일관성·재현가능성이 부족하며 일부 성과가 손실되는 것이 핵심 문제다.
